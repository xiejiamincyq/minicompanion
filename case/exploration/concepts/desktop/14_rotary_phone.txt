ASSEMBLY NOTES
══════════════

    1. Body is 2-piece clamshell (top shell + bottom shell)
       - Top shell: screen opening, ring groove, cradle posts, button holes
       - Bottom shell: flat base with weight pocket, PCB standoffs

    2. Install steel weight plate in bottom shell pocket

    3. Mount PCB to bottom shell with M2.5 standoffs

    4. Install ball bearing race in body ring groove

    5. Place rotary ring onto bearing race, install spring return

    6. Mount screen module into top shell recess, connect FPC to PCB

    7. Wire buttons (front face) to PCB tactile switches

    8. Speaker mounts to PCB (or in handset if option B)

    9. Join top and bottom shells (4x screws around perimeter)

    10. Place handset in cradle

    Shell join detail:
    ┌────────────────┐
    │   Top shell    │
    │   ┌────────┐   │
    │   │ screw  │   │ ← 4x perimeter screws
    ├───┴────────┴───┤   (hidden by rubber feet)
    │  Bottom shell  │
    └────────────────┘


SPECIAL FEATURES
════════════════

    1. SPINNING ROTARY RING
       - Bearing-mounted ring spins freely around screen
       - Spring return: ring rotates back to home after release
       - Pure fidget satisfaction, non-functional
       - Smooth ball-bearing action
       - Optional: finger holes like real rotary dial
       - Optional: ring position could trigger events (future)

    2. HANDSET CRADLE
       - Decorative 1950s telephone handset sits in cradle
       - Option A: solid decorative piece
       - Option B: speaker in earpiece (pick up to listen)
       - Coiled cord decoration adds authenticity
       - Satisfying handset-in-cradle click

    3. WEIGHTED BASE
       - Steel weight plate (40-60g) in bottom shell
       - Prevents tipping when spinning dial ring
       - Feels substantial and premium on desk
       - Phone-like heft and stability

    4. BAKELITE AESTHETIC
       - Glossy black finish (like original Bakelite phones)
       - Smooth, rounded organic form language
       - Art Deco-inspired details on body edges
       - Chrome accents on cradle posts and ring

    5. LANDSCAPE SCREEN
       - Screen in landscape orientation (natural phone dial position)
       - Surrounded by rotary ring frame
       - Slightly recessed below ring surface for protection
       - Good viewing angle from standard desk position

    6. RETRO PHONE BUTTONS
       - 3 buttons on front face styled as phone base buttons
       - Rounded rectangular caps (chrome or contrasting color)
       - Satisfying tactile click
       - Positioned below the dial area (like real phone buttons)
