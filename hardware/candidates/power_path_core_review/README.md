## 已画入的内容

- BQ24072TRGTR 的 17 个焊盘/引脚，按 TI 的 T 后缀电压型 TS 数据表制作独立项目符号，不能替换成无 T 型号。
- Power Path 的 IN、OUT、BAT 分离，三线受保护电池接口：1=PACK+、2=PACK−/GND、3=电芯本体 NTC。
- 充电、电流限制、计时器及温度分压电阻；充电终止使能；输入/输出/电池去耦。
- EN1/EN2/CE 默认电平与评审接口，状态输出拉到未来的可关断逻辑电源，未增加状态 LED。

J1/J3/J4 是评审图边界接口，不是要求成品增加三个插座；因此没有生产封装。J2 的三线顺序仍需与实际电池包、锁扣连接器及观看方向一起定型。

## 本轮验证

官方 KiCad 10.0.6 CLI ERC：0 错误、0 警告。独立网表校验覆盖 19 个器件、15 条网络、59 个器件引脚；另以故意交换电池正极/NTC 的网表确认校验可以识别该错误。绘图文字整理前后网络一致。

`verify_core.py` 计算了固定电阻±1%和假设 NTC R(T)±5%包络下的分压。0°C 最低电压比为0.259313，大于冷阈最高0.255；40°C最高为0.116017，小于热阈最低0.120。**这仅在包络成立且忽略TS输入漏电时成立，不是实物温窗或电芯安全证明。** 采用40°C表值作保守上限，不插值虚构45°C规格。详细假设与三线故障方向见二审报告。

充电电流名义302.7mA，计算范围268.4–335.0mA；可编程输入档378.4–493.4mA；充电计时器按元件极限最短6.944小时。这些均不等于实际充满时间或电池已许可的充电率。

## 绘图操作记录

KiCad MCP 创建候选项目、生成芯片符号、放置器件并连接61个端子（含两个PWR_FLAG）。MCP自动整理文字后仍有可见重叠，故在备份后仅修改字段位置、字号、标签对齐与GND图形方向；未手写网络或走线。再次导出官方网表、ERC和PDF，并检查前后连接完全一致。工具初始化产生的空白PCB未进行布局，不作为设计成果。
