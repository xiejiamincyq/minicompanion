# 两台设备询价资料包

2026-11-19，草稿，尚未发送。仅用于核实可接工序、物料、交期和独立报价，不构成订单、锁库存或生产放行。

请先阅读《供应商询价草稿_未发送.md》，按标准型双面、经济型正面加背面委外、同一小型代工商全包三种完整范围回复。目标交付为两台，用户不焊接；不要求量产导入或额外认证流程。

| 文件 | 用途 |
|---|---|
| jlc_main_bom_rfq.csv | 两块主PCBA全量分组询价；每板数量与两台净用量分列 |
| jlc_front_bom_rfq.csv、external_back_bom_rfq.csv | 同板按面拆分，供单面经济型加委外对照；不得重复采购完整BOM |
| side_assembly_rfq.csv | 保存态位号/面别对应；仅分工，不是CPL坐标文件 |
| bom_by_ref.csv | 位号、精确品牌/MPN/C号、封装及板外装配域追溯 |
| offboard_materials.csv | 屏、电池、开关、探头、外壳和五金等范围，未定尺寸/型号明确列为待确认 |
| excluded_from_main_placement.csv | 随PCB制作的焊盘、孔和测试点，不额外购买元件 |
| 线束与探头代装要求.md | 两线POWER、电池和NTC接线及代装检查要求 |
| 缺料替代核对_20261119.md | 精确料号候选与供货待确认项；不得自行替换 |

CSV为UTF-8 BOM编码。空白报价/备料数量表示待回复，不是零费用。主板净需数量不包含生产损耗或最低上机量，由供应商单列。

Gerber、CPL、原理图、BOM和外壳STL应由同一版本统一提供。请根据所收到的附件明确报价条件、缺失文件或不能承接项目；文件齐备也不代表已经下单或授权开工。KiCad源导出若有负Y坐标，不得手动取绝对值或反转；需要与同源Gerber、面别和方向一起导入审查。

器件网页目录或国际库库存线索不构成国内库存承诺。请按国内可贴仓与精确型号回复；不能承接的板外工序请明确列出，不能默认转交用户焊接。未提供应用固件，不承诺应用功能已经验证。
