# Mini Companion V1：硬件冻结前的软件开发说明

2026-09-22。用户要求现在明确可提前开展的软件工作。本文件用于电脑原型和独立业务逻辑；不是最终烧录规格，也不表示硬件已冻结。最终SOFTWARE_REQUIREMENTS.md和SOFTWARE_AGENT_PROMPT.md仍在硬件定型后交付。

## 产品范围

- 首批5–10台，单台完整材料预算目标50–100元，第三方打样/贴片。
- 至少两天续航；每天约20分钟使用，其余时间待机。待机时NFC持续可用程度尚待功耗与唤醒能力验证，不承诺关机碰触可唤醒。
- 尽量便携；两台同款设备在指定区域接触时识别并互动，双方都有反馈。
- ESP32-S3-MINI-1-N4R2、HS20HS072RX屏、LEFT/OK/RIGHT三个操作键、独立POWER、单节锂电和USB-C。无Wi-Fi业务、BLE依赖、云账号或远程服务器；无声音、电机、状态LED。
- 原仓库firmware目录目前只有README；packages中的服务端和客户端属于原Devotchi联网通知产品，不是Mini Companion固件基础实现，不要求先运行它们。

## 现在可以实现

制作本地电脑可运行的灰盒原型，显示两个独立设备A/B，分别具有设备ID、页面状态和存储。键盘映射LEFT/OK/RIGHT，同时提供显式的接触/移开、断链、断电、重启、电池状态模拟控件。调试控件放在设备屏幕外，不出现在产品页面内。

屏幕像素矩阵按240×320建立，横竖方向做成可配置；最终装配方向未冻结。原型只用于验证交互，不能宣称浏览器UI代码可以直接烧录ESP32。

| 页面/状态 | 必须内容与行为 |
|---|---|
| 启动 | 进入Home；恢复已持久化记录；异常数据不会导致反复重启 |
| Home | 简单陪伴形象占位图、设备状态、电池状态、菜单入口；不增加喂养/养成等未要求系统 |
| 导航 | LEFT/RIGHT移动选择，OK确认；子页有可选“返回”，不依赖触摸或额外按钮 |
| NFC | 等待接触、识别中、待确认、成功、连接中断/重试；文案不把等待写成成功 |
| 相遇结果 | 对方设备标识、已确认碰触次数、最后一次已确认互动；重复报文不重复计数 |
| 设置 | 背光和屏幕超时的抽象设置；具体亮度范围和省电参数可配置，默认值不是续航保证 |
| 设备信息 | 本机ID、软件版本；硬件版本可显示“待定” |
| 电池/充电 | 支持正常、低电、充电、未知的模拟状态；无校准数据时不伪造精确百分比或剩余小时 |
| 待机/断电 | 超时熄屏与真正断电分开；重要状态及时持久化，不假定机械断电前总有回调机会 |

## 相遇记录和离线时间

1. 本机ID首次初始化后保持稳定；重启不生成新ID。模拟器A/B必须不同。实际硬件ID来源稍后确定，不把收到的ID当成安全身份认证。
2. 一次相遇有稳定的会话标识；重复帧和同一会话重试不增加计数。模拟器以移开后再次接触作为新一次触发；实际RF去重/移开检测时序留在硬件适配层。
3. 分别保存本地待确认和已确认记录。持久化失败不能显示已经可靠保存。
4. 断链可能导致两端暂时状态不同，不承诺无线交互下绝对同时提交；恢复通信时按会话标识核对和补全。验收关注无重复、状态诚实及可恢复。
5. 开机期间可使用单调时间做超时。当前无硬件断电日历保证；掉电后若没有可信时间来源，“距上次见面3天”必须显示时间未知，仍可显示上次对象和累计次数。
6. 记录格式包含版本和完整性/恢复方案。容量和保留策略可配置，不能无限增长；最终Flash写入策略待固件阶段落实。
7. 长期绑定、秘密留言、纪念日、关系等级、复杂养成均不作为本轮必做项。原需求的配对/识别基础先落实为本次双方身份交换及确认，不擅自强制永久一对一绑定。

## 与硬件隔离的接口

以语义事件和服务隔离业务：Input提供LEFT/OK/RIGHT事件；Display渲染页面；NfcTransport提供发现、收发、断链事件；Storage负责持久化与故障注入；Clock区分单调时间和可信日历；Power提供电池/充电/供电状态；Backlight提供亮度和关闭控制。具体语言和库由软件代理评估，业务代码不直接写GPIO或寄存器。

目前基线参考：正面看元件层、USB向下时，左GPIO5、中GPIO6、右GPIO4；按下为低。最终以冻结后的硬件表为准。NFC接口/GPIO、充电状态引脚、ADC分压与校准、POWER检测能力、显示初始化/方向和待机唤醒条件均不得自行假定已确定。

## 本阶段验收

- 用户能按README在电脑启动原型，用三个键完成页面导航，无需购买硬件。
- A/B模拟正常接触后各记录一次；保持接触和重复报文不会累计增长；移开后再接触可形成新记录。
- 交换/确认/保存各阶段可注入断链或掉电；重启保留已可靠保存数据，待确认状态可恢复，不伪造双方完成。
- 存储异常、对方ID等于本机、未知协议版本、无效/过长消息都有明确处理，不造成崩溃或无限重试。
- 无可信时钟的重启不显示虚假的间隔天数；低电和充电状态可以演示。
- 给出自动测试结果、运行说明、模拟与真实硬件的差异、尚待接入的接口清单。
- 原型验证不能用作NFC射频可用、实机省电、两天续航或充电安全的证明。

## 用户怎么开始

将同目录SOFTWARE_EARLY_AGENT_PROMPT.md的全文交给另一个软件代理，或将两个文件一起附上。先拿到可在电脑操作的原型和测试，再考虑接硬件。无需安装KiCad来做软件，也无需先购买板卡。

软件任务使用独立目录/工作树；不与硬件代理同时修改hardware、case或现有硬件文档。完成后把原型截图、运行说明和硬件依赖清单带回硬件任务核对。
