    ┌───────────┘
    │ Latch point


ASSEMBLY NOTES
══════════════

    1. Mount PCB to bottom of body cavity with M2.5 standoffs
    2. Connect screen FPC cable through carriage slot to PCB
       (use flexible ribbon cable with slack for travel)
    3. Attach screen module to carriage frame (4x M2)
    4. Insert compression spring into central guide post
    5. Slide carriage onto rail channels, compress spring
    6. Install lever mechanism on left side wall
    7. Connect button actuators (front face) to PCB tactile switches
    8. Install brightness slider potentiometer on right side wall
    9. Route speaker wires, speaker mounts in body cavity
       (sound exits through bread slot opening)
    10. Snap or screw body shells together (2-piece clamshell)

    FPC cable routing (critical):
    ┌─────────┐
    │Carriage │
    │         ├──╮
    │  Screen ├──┤ ← FPC ribbon folds in Z-pattern
    │         │  │   to accommodate 50mm carriage travel
    └─────────┘  │
                 │
    ╔════════════╧══╗
    ║     PCB       ║
    ╚═══════════════╝


SPECIAL FEATURES
════════════════

    1. SPRING POP-UP MECHANISM
       - Push lever down: carriage descends into body, screen hidden
       - Magnetic latch holds carriage down (sleep mode)
       - ESP32 releases magnetic latch on wake: screen pops up
       - Satisfying spring action with gentle damping

    2. BRIGHTNESS SLIDER (Toast Darkness Control)
       - Vertical slider on right side
       - Labeled "LIGHT ─── DARK" (reversed for humor)
       - Controls actual screen brightness via potentiometer

    3. TOAST-STYLE BUTTONS
       - Button 1: "CANCEL" — left button
       - Button 2: "DEFROST" — center button
       - Button 3: "BAGEL" — right button
       - Retro toaster labeling, functional Devotchi controls

    4. SPEAKER THROUGH SLOT
       - Sound exits through the bread slot opening
       - Creates a natural resonance chamber effect
       - Slot doubles as speaker grille

    5. CHROME/STAINLESS AESTHETIC
       - Body: brushed stainless steel look (metallic PLA or
         actual sheet metal wrap)
       - Rounded retro proportions (1950s Sunbeam toaster style)
       - Lever: chrome-look plastic or metal
       - Warm, kitchen-friendly desk presence

    6. SLEEP/WAKE INTERACTION
       - Push lever → satisfying click → screen descends → sleep mode
       - Wake event → magnetic release → spring pop → screen rises
       - Physical theater for digital state changes
