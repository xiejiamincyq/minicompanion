DESIGN 3: PEBBLE
================
Smartwatch-inspired rounded rectangle with an organic, stone-like feel.
Minimal front face — just the screen, nothing else visible from front.
All buttons on the sides like a watch crown + pushers.
Think "Pebble watch" or "river stone" aesthetic.

Overall: 62mm tall x 50mm wide x 16mm deep
Weight target: ~42g with battery
Orientation: Portrait
Corner radius: 10mm (very rounded, almost pill-shaped)
Shell: 2-piece (front + back), 4x M2 screws

COMPONENT LAYOUT (exploded, front to back)
──────────────────────────────────────────

    Layer 1 — FRONT SHELL (1.5mm wall, 10mm corner radius)
    ├── Screen window cutout (41.8 x 31.6mm, portrait, centered)
    ├── Translucent LED strip at top edge (8 x 1.5mm)
    ├── 4x screen retention clips (L-shaped, 0.5mm overhang)
    ├── NO front-facing button holes (clean face)
    ├── 3x right-side button slots (13 x 7mm cutouts)
    ├── 1x left-side button slot (11 x 5mm cutout)
    └── 4x M2 threaded inserts (heat-set, brass)

    Layer 2 — DISPLAY MODULE (51.8 x 36.2 x 2.5mm)
    ├── Portrait orientation (rotated 90deg)
    ├── Centered in front shell pocket
    ├── FPC exits bottom edge
    └── Held by front shell retention clips

    Layer 3 — 2.5mm AIR GAP
    ├── FPC routes to PCB connector
    └── Side-button plungers route here

    Layer 4 — PCB (45 x 40 x 1.6mm)
    ├── ESP32-S3-MINI-1 faces back
    ├── 3x right-angle tactile switches on right edge
    ├── 1x right-angle tactile switch on left edge
    ├── USB-C on bottom edge (centered)
    ├── Display FPC connector on top edge
    ├── LED on top edge (shines through translucent strip)
    ├── Vibration motor pads (bottom area)
    └── Mounted on 4x M2 standoffs

    Layer 5 — 0.5mm GAP + BATTERY (30 x 35 x 5mm LiPo)
    ├── Centered in back shell
    ├── JST pigtail to PCB
    └── Foam tape retention

    Layer 6 — BACK SHELL (1.5mm wall, 10mm corner radius)
    ├── 4x M2 countersunk screw holes
    ├── 4x standoff bosses
    ├── Battery retention area with foam pad
    ├── USB-C cutout (9.5 x 4.0mm)
    └── Optional strap loop / clip rail (see variants below)

MOUNTING / ASSEMBLY NOTES
─────────────────────────
- Shell: 2-piece rounded rectangle, 4x M2 screws from back
- 10mm corner radius gives very soft, organic look
- Front face completely clean — no visible buttons or holes (except screen)
- All 4 buttons on side edges, using right-angle tactile switches
- Side button caps are separate pieces that slide into shell slots
- LED hidden behind translucent plastic strip at top edge
- PCB requires right-angle switches on both left and right edges
- USB-C cutout on bottom edge, accessible when worn on wrist
- Back shell variant system: swap back shells for different
  attachment methods (strap, clip, plain)
- Very rounded profile is comfortable in hand, pocket-friendly
- Display in portrait mode to maximize vertical screen real estate
