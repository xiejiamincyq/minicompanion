## U216接口逐项核对

依据[官方原理图V0.1](https://m5stack-doc.oss-cn-shenzhen.aliyuncs.com/1229/SCH_Unit_NFC_V0.1_2025_11_28_12_15_35.pdf)，本地下载用于目视检查；原厂资料版权仍归厂商。

| 原理图端点 | 连接证据 | 对主板设计的约束 |
|---|---|---|
| J1.1 / J1.2 | SCL / SDA；R3、R4各2.2k上拉至模块VCC_3V3 | 不能把信号颜色当引脚序；需要校验主板与模块不同电压域及掉电次序，不直接再并联强上拉 |
| J1.3 / J1.4 | +5V / GND | 电池模式下不能只接USB VBUS；需要受POWER控制的合适供电，当前3.18V轨不能作为5V接口已验证供电 |
| U3 VIN/EN | 都接+5V，VOUT产生模块3.3V | 不能假定整板支持3.18V输入；绕过LDO属模块改造，不作为无需验证的默认方案 |
| U1.27 IRQ | 明确NC，未引至Grove | 原样模块不能提供外部IRQ唤醒MCU；深睡期间仅靠这四根线不能承诺RF事件即时唤醒 |
| U1.28 MCU_CLK | NC | 不假设模块提供主机时钟 |

原样模块后续供电设计至少应包含：电池供电时可用的电压转换、POWER关闭时断开NFC供电、上电浪涌预算、SDA/SCL的掉电反灌审查。不得直接把模块连到常通SYS_RAW并宣布关机无旁路。额外电路的成本和效率必须加入整机比较后再决定。

## 源码证据：可研究，但不是双机验证通过

按用户要求，仅通过GitHub插件读取[m5stack/M5Unit-NFC](https://github.com/m5stack/M5Unit-NFC)，固定版本 `63c4caac1a07018ef73027e4b098d4fefe56c6f6`。

- [NFC-A示例说明](https://github.com/m5stack/M5Unit-NFC/blob/63c4caac1a07018ef73027e4b098d4fefe56c6f6/examples/UnitUnified/NFCA/Emulation/README.md)提供NTAG21x/Ultralight类模拟，并非已提供Type-4 APDU例程。
- [模拟层](https://github.com/m5stack/M5Unit-NFC/blob/63c4caac1a07018ef73027e4b098d4fefe56c6f6/src/nfc/layer/a/emulation_layer_a.cpp)的WRITE_PAGE路径可更新模拟内存。因此可研究自有Type-2页式邮箱交换应用ID，无需把Type-4当作用户硬性要求；尚未验证双向会话和掉电一致性。
- [驱动](https://github.com/m5stack/M5Unit-NFC/blob/63c4caac1a07018ef73027e4b098d4fefe56c6f6/src/unit/unit_ST25R3916.cpp)的wait_for_interrupt在未使用IRQ时通过总线读取中断状态。没有IRQ引线并不等于读写/模拟必定不可用，但轮询不能等同于MCU深睡RF唤醒。
- 本轮只读源码，不编写、编译或移植用户软件；没有两台ESP32-S3实机结果。必须测量显示刷新、调度延迟和角色切换对响应时序的影响。

## 成本和两天续航边界

见`calculate.py`和`assessment.json`。保持power-013历史报价不变，以便回溯：10件档五项已报价部件11.3606美元，加U216为18.3606美元。在假设7元/美元的情景下为128.52元，尚缺其余电源IC、无源件、电池、PCB、装配和新增NFC供电。它比原PN7160模块便宜，但不能据此宣布整机100元达标。国内屏幕页面的“起价”没有5/10件档确认，本轮不将其当作小批实价填入预算。

厂商[文档](https://docs.m5stack.com/en/unit/Unit_NFC)给出的连续读卡示例功耗为5V×67.65mA，休眠示例19.33µA；两者都不是本机模式的保证最大值，更不包含ESP32、转换器及其他整机负载。不能用模块微安休眠值替代整机待机电流。

仅作容量敏感性分析：每天20分钟活动，两天共40分钟；假设非NFC活动负载3.18V×200mA、转换效率85%、电池标称3.7V、可用容量系数80%，活动期叠加上述NFC读卡功耗。500mAh电池留给其余47小时20分钟待机的电池端平均电流约4.09mA，800mAh约9.16mA。200mA、效率和可用系数均为工程假设，不是测量或最终电池规格；高频轮询会使待机预算成为关键风险。500/800mAh只是计算情景，未承诺能装入外壳。
