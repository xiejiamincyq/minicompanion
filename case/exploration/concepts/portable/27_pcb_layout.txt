DESIGN 27: PCB COMPONENT LAYOUT
=================================
Top-down view of the 45x40mm PCB showing component placement,
connector positions, and alignment with the case/display.
Components face FRONT (toward display). USB-C on bottom edge.

PCB: 45.0mm wide x 50.0mm tall x 1.6mm thick
Position in case: centered X (7.5mm inset), bottom-aligned (8.5mm from top)
Case: 60 x 60 x 15.1mm
Mounting: 3x M2 holes (2.2mm), 3mm inset — TL removed for FPC connector

IMPORTANT CONNECTOR ALIGNMENT NOTES:
- Display FPC exits LEFT edge of module HORIZONTALLY, ~15.3mm from display top
- FPC cable must fold downward in the gap between case wall and PCB edge
- FPC connector (FPC301) near TOP-LEFT of PCB, latch facing LEFT to receive cable
- USB-C connector centered on BOTTOM edge, protruding 1.95mm past PCB
- Buttons on FRONT face must align with case button holes
- ESP32 antenna must be at TOP edge with keepout zone

    Hole    PCB X     PCB Y     Case X    Case Y

    BL      3.0       42.0      9.6       54.7
    BR      42.0      42.0      48.6      54.7

    Back cover has 3 matching standoffs:
    - 4.0mm outer diameter
    - 5.5mm tall (from back inner wall to PCB solder side)

ESP32-S3-MINI-1 PLACEMENT
──────────────────────────

    Module: 15.4 x 20.5 x 2.4mm
    Position: right side of PCB, antenna at TOP edge
    X: ~20mm from PCB left (right-biased to leave room for FPC)
    Y: ~2mm from PCB top edge (antenna flush with PCB top)

    CRITICAL: Antenna keepout zone
    ┌─────────────────────────────┐

FPC CONNECTOR (AFC01-S12FCA-00) DETAIL
──────────────────────────────────────

    JUSHUO AFC01-S12FCA-00
    LCSC: C262661
    12-pin, 0.5mm pitch
    Bottom-contact type

    ┌─────────────────────┐
    │  ┃┃┃┃┃┃┃┃┃┃┃┃      │  ← 12 pins (0.5mm pitch)
    │  1            12    │     Pin 1: GND
    │                     │     Pin 12: GND
    │  ▓▓ latch ▓▓       │  ← Flip-lock latch
    └─────────────────────┘
          ↑
          Latch faces LEFT (toward case wall)
          FPC cable enters from LEFT side

    FPC cable inserts with contacts facing DOWN
    (same-side contact configuration)

    ORIENTATION ON PCB:
    - Connector rotated so latch/cable-entry faces LEFT
    - Pins run vertically (top to bottom)
    - This allows FPC from display left edge to
      fold down and enter from the left


POWER SECTION PLACEMENT
────────────────────────

    Right side of PCB, below ESP32:

    ┌──────────────────────┐
    │  TP4056 (SOP-8)      │  ← LiPo charger IC
    │  + Rprog (3kΩ)       │    ~330mA charge rate
    ├──────────────────────┤
    │  DW01A (SOT-23-6)    │  ← Battery protection IC
    │  + FS8205A (SOT-23-6)│    Over-discharge/charge/short
    ├──────────────────────┤
    │  ME6211 (SOT-23-5)   │  ← 3.3V LDO
    │  + C_in, C_out       │    500mA max, 100mV dropout
    └──────────────────────┘

    Power flows: USB-C → TP4056 → Battery ↔ DW01A
                 Battery → ME6211 → 3.3V rail
