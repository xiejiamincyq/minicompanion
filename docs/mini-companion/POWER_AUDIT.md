# 电源与充电安全只读审计（HW-PWR-AUDIT-001）

日期：2026-09-19。范围为 `hardware/power.kicad_sch`、`hardware/devotchi.kicad_pcb`、BOM 和由 KiCad 10.0.6 导出的基线网表；本报告没有修改原理图、PCB、固件或 Git 状态。

## 结论与必须暂停项

**当前设计不得进入制板或装配。** 有一项架构阻断项，另有一个必须保存复核的 PCB 状态项：

1. `baseline/drc.json` 在未保存的基线状态下有 11 个 error：R202/U201-CS 邻近 GND 填充区发生 0 mm 间距、过孔孔间距和顶层阻焊桥接；J202 两个无网络机械焊盘与 GND 填充区发生 0 mm 间距及底层阻焊桥接。总控已复核，内存执行 `--refill-zones` 后这 11 项均消失。因此它们**不能被判断为确定实物短路**，但也尚未写回 PCB；制板前必须保存填充区并重新导出 DRC=0 的证据。
2. U202（TP4056）BAT 输出直接就是 `+BATT`，而 U203/LDO 与整机负载也直接取自 `+BATT`；没有 `SYS/OUT` 电源路径、理想二极管或负载分担。这使“边充边用且能可靠充满”不成立。TP4056 的终止判断会把系统负载混入电池电流。README 中约 140 mA 的活动功耗只是上游估算，不能用于 V1 安全结论；V1 已关闭 Wi-Fi、删除电机，并包含尚未定量的 NFC 功耗，必须以实测负载曲线替代该估算。

在选择下文路线并修复 DRC 前，暂停对外下单、装配和任何“可安全边充边用”的功能承诺。

## 已核实的实际网络

以下为基线网表与 PCB 焊盘一致的结果，而非 README 推断。

| 功能 | 实际连接 | 审计判断 |
|---|---|---|
| USB-C 取电 | J201 A4/A9/B4/B9 → `VBUS` → C202(10 µF) → U202.4 VCC；J201 A5/B5 各经 R204/R203=5.1 kΩ 到 GND | 作为 Type-C 受电端的 CC Rd 网络正确；未见 VBUS 保险丝、TVS 或输入过压钳位。 |
| 充电控制 | U202.8 CE=`VBUS`；U202.2 PROG → R205=3 kΩ → GND；U202.1 TEMP → R206=10 kΩ → GND | CE 随插入 USB 启用。厂家只验证了 TEMP **直连**地可禁用温感；本板经 10 kΩ 下拉，且公开资料未给 TEMP 偏置电流，无法证明有效温监或具体充电行为，须量测 TEMP/VBUS 并做充电启动/暂停测试。R205 值按 TP4056 数据表公式约为 400 mA，README 的“约 330 mA”不准确。 |

| 电量 ADC | `+BATT` → R207=100 kΩ → BAT_ADC → R208=100 kΩ → GND，BAT_ADC 到 U101 IO2 | 满电约 2.1 V，电压幅度安全；分压静态耗流约 21 µA（4.2 V 时），且 PCB 未布 ADC 到地电容。官方 Espressif 指引要求 ADC 引脚加 0.1 µF 滤波；README 声称 GPIO1，而实际网表接 ESP32-S3 IO2，固件引脚配置必须以网表为准。 |

## 元件资料与风险解释

TP4056 原厂资料说明：TEMP **直连**地会禁用温度感测；PROG 通过接地电阻设定充电电流；CHRG/STDBY 是开漏状态输出；终止发生在恒压阶段、充电电流降至设定值约十分之一。资料也列出了 TEMP 处于常规监测状态时的 45%/80% VIN 暂停阈值。R206=10 kΩ 不是资料所示直连，且公开资料没有给 TEMP 偏置电流；因此既不能把它判定为已禁用，也不能把直短规则外推为它必然处于暂停窗口。样机须量测 TEMP 对 VBUS 的比值，并验证插 USB 后的实际启动、暂停与温度响应。现有电路没有接入电芯 NTC，不能作为已验证的温度充电保护；R205=3 kΩ 按数据表关系式约设为 400 mA。

对 300 mAh 电池而言，400 mA 约为 1.33 C；对 500 mAh 约为 0.8 C。BOM 只写“300–500 mAh LiPo”，没有给出所选电芯允许充电倍率、是否自带保护、NTC 或认证信息。因此在确定具体电芯前，400 mA 不是可批准的安全参数。

DW01A + FS8205A 可提供单节电芯的过充、过放和放电过流/短路保护，但不等同于充电温度管理、USB 瞬态保护或系统电源路径。`+BATT` 是保护电芯正端与整机负载的共同节点；在 USB 插入时，负载仍在 TP4056 的 BAT 端上。

ME6211 的输入和输出各有 1 µF 电容，网络上满足最基本去耦的形式；但它是线性 LDO，V1 的 NFC、屏幕背光及其余保留负载的峰值电流会直接转化为电池侧压降与热。现有文件没有给出 NFC 的工作/峰值电流，也不足以证明 3.3 V 在最低电池电压与 V1 实际负载组合下稳定；这属于样机验证项。

## 可选安全架构（需总控/用户决策）

### 方案 A：保留 TP4056，硬件隔离负载的仅关机充电

保留 TP4056 和保护拓扑，但新增**硬件**负载隔离和系统正电源开关，使系统在关机充电时与 BAT 端负载物理断开；保护 MOSFET 的电芯负极路径不得作为系统开关切断点。充电路线接入电芯 NTC（或采用经资料确认可充的匹配电芯与温度策略），并依据该电芯的推荐/最大充电电流设定 R205。必须新增可靠的 VBUS 检测硬件，不能依赖目前不存在的可靠软件检测来实施安全模式。

该路线的产品规范必须是“关机充电”，不提供插 USB 时的系统运行。它不能通过关 Wi-Fi、背光或删除电机来替代硬件隔离。优点是器件替换较少；代价是需要新增隔离/开关、NTC/匹配电芯、VBUS 检测、ESD、输入限流和状态上拉的硬件闭环。

### 方案 B：改为带 PowerPath 的充电架构（推荐）

以带系统输出和动态电源路径的单节充电器替换 TP4056，或设计经验证的外置理想二极管/PMOS 负载分担；系统从 `SYS/OUT` 供电，电池只接 `BAT`。TI BQ24074 是可研基准：其资料明确支持系统与电池同时独立供电/充电，并通过 DPPM 在系统负载上升时降低充电电流，同时提供输入电流管理。具体料号必须按封装、可得性、USB 默认电流、电池 NTC 和系统峰值电流重新选型，不应直接把 BQ24074 视为已批准 BOM。

BQ24074 的 OUT 标称为 4.4 V（规格范围 4.3–4.5 V），不可以直接把它当成现有 `+BATT` 的等价网替换：必须分别复核 ME6211 输入最高额定值与热、显示背光的 R301 值/LED 电流、ADC 分压满量程及其他直接接 `+BATT` 的负载。方案 B 同时应纳入：电芯 NTC/TS 检测、USB 口 ESD（VBUS 和 D+/D−）、合适的输入限流或受控 USB 电流、CHRG/STDBY 外部上拉、ADC 0.1 µF、以及明确的屏蔽/机壳地策略。完成这些后，才可定义“插 USB 时可持续使用、正确充满且电池可补峰值”的验收测试。

### 路线比较（定性；工期为工程量级估算）

| 项目 | 方案 A：关机充电 | 方案 B：PowerPath |
|---|---|---|
| 产品能力 | USB 插入时系统硬件断电，只充电 | USB 插入时可运行，充电器独立管理系统与电池 |
| BOM 变化 | 增加系统正电源开关/隔离、VBUS 检测、NTC/匹配电芯、ESD/限流/上拉；保留 TP4056 | 替换 TP4056，增加/调整 PowerPath 配套 RC、输入限流、NTC、ESD、上拉；可能需调整 LDO、背光和 ADC 分压 |
| PCB 变化 | 中等：切断系统正电源并保留保护负极路径，增加器件和走线 | 高：重画充电区与系统电源网，核对所有原 `+BATT` 消费者并处理 OUT 电压 |
| 验证量 | 中等：关机隔离、充电终止、温度、短路/保护 | 高：上述项目外加 USB 插拔、DPPM、带载充电、峰值负载、无/欠压电池启动 |
| 工期估算 | 约 1 个硬件迭代；取决于电芯与 NTC 资料到位 | 约 1–2 个硬件迭代；取决于新 IC 选型、布局和带载测试 |

## 下一步验收条件

1. 保存填充区重填结果后，KiCad DRC error 为 0，且重新导出的 PCB 与原理图网表一致；不能只接受 warning 计数变化。
2. 选定电芯须提供容量、最大持续放电、推荐/最大充电电流、保护状态、NTC 与认证资料；据此复核 R205 和热设计。
3. 负载阶跃测试覆盖 V1 实际 NFC、满背光及其余已保留负载，并覆盖 USB 插入/拔出，记录 `+BATT`、`+3V3`、充电器温升与充电终止行为；Wi-Fi 和电机不属于 V1 验收负载。
4. 验证 DW01A 保护阈值及恢复行为，并验证 ESD 后 USB、充电和 MCU 不损坏、不锁死。
5. BAT_ADC 用实际 IO2/ADC1 配置，加滤波后在 3.0–4.2 V 用基准表校准；验证系统关闭、USB 插入和各电源时序下 ADC/MCU 引脚均无反灌。机械电源开关应切断系统正电源，不能切断 DW01A/FS8205A 的保护负极路径；不能沿用 README 的 GPIO1 标注。

## Astra 二审补充

- A路线“USB插入系统必断电”与必须保留USB烧录/调试存在冲突，不能原样冻结。若用户选择A，必须单独设计有硬件充电禁能的服务/烧录状态并复审；这会削弱A的简单性，故推荐B。
- ADC约2.1V仅为MCU正常供电时的标称计算，不证明关机时输入安全；反灌隔离是最终POWER设计的必验项。
- 裸板保护测试使用限流电源/电芯模拟器和受控负载；不让初学者通过直接短路真实锂电池进行验证。
- 充电器具体供应商的参数不能仅凭通用TP4056名称移植；最终料号以准确数据表、电芯规格及测量结果共同冻结。
