# A2 两台样机交付验收

以下为代装方的实物工序。每台分别保留读数和通过/返修结论。先用限流台源、万用表、可吸收充电电流的电芯模拟器或合适电子负载完成电路检查，再装合格的保护电池。充电禁用时，用断开输入的测量作漏电基线并记录仪表分辨率。电路图的检查结果不能代替这些读数。

| 工序 | 验收内容 | 记录 |
|---|---|---|
| 无电配线 | 核心 V2 原生 USB-C、排针方向及 BAT/VBAT 空置。检四针电池/探头束线和两针 RUN 线端点，五针核心线检测线接核心的 5V。确认电池线无短路、极性正确，RUN 源端 USB-C 插头正确，未用线芯逐根绝缘。圆口电源输出 5 V、中心正，未插时机械触点闭合，插入后开路。 | 接口、极性、阻值 |
| 日常关机与开机 | 使用模拟电池，逐次验证侧拨 OFF、RUN。OFF 时核心失电、屏灭、BLE 断开。RUN 时在核心端测 5 V，分别记录启动、屏点亮、BLE 收发时的电压/电流，观察是否棕断或异常发热。在电池工作电压下限附近检查欠压关断和恢复，不能反复重启。 | 空载/负载、门限、温升 |
| 充电和两路供电 | 在 RUN 挡运行时插入**未通电**圆头，用示波器同步记录核心 3V3 和充电电流，验证每次均先停机、后开始充电。随后接上配套 5 V，确认核心停机后电池模拟器收到充电电流。交换插拔顺序再测一次。用电脑 USB 数据线供电时同时插圆口，确认核心可烧录、电芯实际充电电流处于禁用基线；断开电脑线后须恢复正常充电。 | 降压时间、各模式毫安读数 |
| 真实电芯测温 | 先用模拟电芯，保留本机实际探头、线束、贴装方式及同形热夹具。室温应可充电；开路和短路均禁充。用独立温度计贴在探头旁，分别从室温缓速冷却、升温并等待热平衡，**在 +2 °C 和 +42 °C 都必须已经禁充**；在充电小板热稳态和装壳贴合状态再复验，记录各次停充、恢复温度和实测电流。不得用环境温度或静态电阻代替整条链。只有两个端点与室温全部通过才放行该机。 | 冷端、热端、回差、实测电流 |
| 充电完成 | 实测投入的充电电压、电流和终止电压满足图纸及电池规格。核 4.10 V 标称、电流约 0.30 A，并在正常配套电源、健康电池和室温下测试能否在安全定时器内充满。记录贴合后的升温和最高壳内温度。 | 电压、电流、耗时、温度 |
| 烧录与无线 | 普通数据线经原生 USB-C 完成烧录、断电重启和 BOOT/RESET 恢复。用测试固件检查三个按键、屏幕、A↔B 两机 BLE 双向数据以及 A、B 各与手机连接，一并记录裸板与闭壳结果。约 20 分钟使用/日、隔两天可用的续航目标需按实际使用和待机测量。 | 固件版本、通讯、按键、续航 |
| 固定与装壳 | 检查电芯软包、绝缘探头、温度贴合、无受压鼓包、主板不夹线。轻拉外侧短线由护套和固定点承力，插拔圆口/USB-C 无松动。市电适配器闭壳成品供货。 | 样机 1 / 样机 2 |

核心供电检测线开路时，硬件会把它当作核心无电。该故障会使「电脑线和充电圆口同时插入」的附加禁充失效；正常圆口插入对电池供电的硬件停机由独立机械触点完成。代装时应固定检测线、验证两个插入顺序，并把断线时的现象用于线束返修定位。探头从电芯脱胶也会使其读到壳内温度，因此独立卸力、贴合与温度验收均列入代装范围。若某台在保护或端点试验未通过，应保持电池断开，返修并重测后再交付。
