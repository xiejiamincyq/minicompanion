# HS20HS072RX 电源约束复核

2026-09-21，Astra；来源为仓库原厂文件 `docs/display/HS20HS072RX_datasheet.pdf` 第4–6页。此文件约束后续电源设计，不表示已经改变电路或完成实测。

- 背光为四颗并联白光LED。第5页绝对最大电流80mA；第6页在80mA条件下列出Vf最小/典型/最大2.8/3.0/3.2V。不能给恒流源设定80mA典型值后再允许正误差；初始设计取60mA，必须核算驱动器和设定电阻公差，使最大实际电流低于80mA。亮度需样机确认。
- 屏幕逻辑正常和休眠电流均为TBD。不能把“ESP32+屏逻辑250mA”写成原厂保证的上限。预算必须区分设计预留、数据表测试值和实测峰值。
- IOVCC和VCI的推荐运行上限均为3.3V。3.3V名义稳压的正公差、纹波和负载卸载过冲必须纳入审查；4.6V绝对最大不能当作正常运行规格。可研究降低共同逻辑电源设定值，但需同时满足ESP32、NFC模块及所有数字接口的最差条件，尚未冻结。
- 若背光从SYS经独立驱动供电，应在SYS功率预算中计入，不能同时作为3.3V输出负载重复计算。3.3V转换器的裕量可另行保留，需标注为工程裕量。

示例仅用于初始包络：假设逻辑支路550mA@3.3V（其中NFC300mA仍为预留），转换效率85%，背光为SYS端60mA线性恒流负载；在SYS=2.8V时估算输入为 `3.3×0.55/(2.8×0.85)+0.06≈0.823A`，未计路径压降及其他损耗。此时SYS低于LED可能需要的3.2V，线性恒流无法保证额定亮度，驱动拓扑仍须解决低电池电压工况。该示例不是已通过的运行点。

正式预算还需：ESP32配置及瞬态负载、电芯最低工作电压、保护板导通电阻、NFC射频配置/天线电流、屏逻辑实测、LED驱动效率/压差、USB可用输入档位。无这些证据不能发布续航或满载边充边用承诺。
