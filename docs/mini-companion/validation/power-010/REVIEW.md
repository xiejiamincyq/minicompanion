# HW-PWR-010 CC条件组合候选

2026-09-27，Astra实施，独立代理只读二审。新增usb_qualify子页；此阶段只完成电源监控和CC条件组合，**没有完成充电器EN控制，也没有形成可打样电源系统**。

## 已落实到原理图

U5 TPS3808G33DBVR监控USB_3V3，SENSE/VDD/MR接同一轨，RESETn命名USB_READY，经100k上拉；CT用180nF±5%对地。U6 SN74LVC1G97DBVR配置为 `Y = USB_READY AND NOT CC_OUT1`：1=READY、2=GND、3=GND、4=Y、5=USB_3V3、6=CC_OUT1。两个芯片各100nF去耦，输出CC_HIGH_QUALIFIED经10k下拉，J7是评审边界。

该单门方案省去独立反相器，施密特输入适合开漏慢边沿。R9从200k降为10k±1%，改善接收器最大5µA漏电造成的压降：1.01V降至50.5mV；TUSB自身关闭态输出漏电没有最大值保证，不能把50.5mV称为全部误差。低电平时该上拉消耗约0.33mA，计入旁路预算。R10仍200k，本次没有接新增接收器。

## 二审与剩余条件

- TPS3808 G33下降门限全温计算3.02395–3.11605V。100k上拉考虑RESET 0.3µA及门输入5µA的漏电后，最大电阻压降0.5353V；需与实际电源及门阈值共同复核。
- 180nF表格延时0.62/1.03/1.44s，不包含本次电容额外容差、偏压、温度和漏电。没有把0.62s当实物最短延时。此前CT直接接VDD的提议被否决；固定300ms档需经40–200k上拉，本次采用电容档。
- TUSB CC消抖168ms是典型值；较长监控延迟只提供候选时序裕量，不能据此证明覆盖所有初始化。
- 门电路低于1.65V不保证逻辑。Ioff约束VCC=0，不能覆盖整个掉电过程；10k下拉不能压住未定义区的主动高输出。故当前输出不直接接充电EN。后续必须把充电端默认挂起/独立低压钳位、失去CC许可、短时跌落与输入有效状态一并落实。
- 在有效供电且信号已稳定的逻辑模型中，未连接或Default电流、USB_READY=0均输出0；较高电流宣告且READY=1输出1。这不是USB合规或瞬态证明。Default/BC1.2及电脑挂起策略尚未实现，整机旁路最大电流未封闭。
