# 两台 BLE 设备的采购与代装资料

2026-11-19。本目录交付可复算的询价资料，不是下单授权、锁价或制造放行。目标为两台完整设备合计 **400–600 元，累计最高 1000 元**；上限包含后续可选开支，不限于本次硬件采购。优先嘉立创采购/制板/标准型双面贴装，用户不承担焊接。金额范围为用户目标，不是供应商已接受的报价。

## 成本结论

最新旧账是 2026-11-13 的两台新增采购现金 **499.73 元**。它采用用户自行焊接、排除全部运费，并包含尚未闭合的缺货材料、替代料与参数报价条件，**不能作为当前免焊接方案的总价**。旧账逐行保存在 `source_snapshot/historical_purchase_two_20261113.csv`，本轮用 Decimal 复算为 499.726904 元。

[嘉立创官方入门文档](https://www.jlc.com/portal/server_guide_4018.html)的双面标准型示例列工程费 150×2、钢网费 50×2，合计400元，另计焊点、物料、上料、X-ray及其他费用。这只是官方示例，不是本板报价。仅将它叠加旧499.73元现金，情景小计已约 **899.73元**；若旧主PCB从助手30元条件价改普通网页100元，则约 **969.73元**。两数仍缺新增ECO、线束/探头代工、总装与运费，且旧价可能变化。

因此 400–600 元在现有双面代工路线下较紧，1000 元也尚未得到完整报价支持。不能用未验证优惠或把用户劳动算免费来宣布达标。下一步优先取得同一版 Gerber/BOM/CPL 的整单报价；只有完整金额才决定是否在预算内。旧材料可整包由代工商采购，避免在SMT费用之外重复购买整卷零售耗材。

询价稿同时准备了同板正面经济型贴2块、背面和线束统一委外的路线，以及小型代工商双面全包的对照。两面都有QFN，背面委外需要回流和检查能力；经济型单面不会自动加工另一面。其最低加工费、第二次钢网、损耗及转运仍未知，不能预先宣布更便宜。各路线完整报价单列于 `budget_model.json`，均保持 `null`。拆分时按位号分配备料，不让两家各买完整BOM。

## 更新方法及验收范围

在本目录运行 `python build_sourcing.py`，默认读取本工作树的 `verification/usb_eco.xml` 和 `project/mini_companion_integrated.kicad_pcb`；缺文件会明确报错，不会回退历史版本。也可显式指定这两个输入的绝对路径。脚本不修改CAD；读取PCB仅为面别分工，不输出未审查的贴片坐标。历史对照必须显式指定旧网表、匹配的旧PCB及独立的 `--output-dir`，禁止覆盖本目录当前询价文件。

检查覆盖：每个网表位号一次、主板分组数量守恒、铜特征不重复采购、板外件不混入主板贴装、原型号与C号一致、历史采购账复算、未知报价保留null。检查成功只表示数据自洽；当前 `production_ready=false`，供应商未报价、未发送询价、未下单、未实物验收。正式制造仍需最终CAD/ERC/DRC及生产文件一致性和贴装方向审查。
