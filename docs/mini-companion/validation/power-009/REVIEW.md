# HW-PWR-009 USB CC检测前端

2026-09-24。Astra绘图及复核，独立代理只读二审。已加入system_power_review工程第三张子页usb_cc；仅检测前端，未接充电器EN授权逻辑。J5/J6表示集成边界，不增加实物接口。当前主板仍未替换旧电源。

## 电路

- U3 TPS70933DBVR，原版DBV引脚1输入、2地、3使能、4NC、5输出；不得按A/B版本替换。VBUS供电，EN按官方允许悬空自启。输入2.2µF，输出4.7µF，均暂定10V X7R；实际料号和有效容量待定。
- U4 TUSB320LAIRWBR，PORT/EN_N接地，ADDR明确悬空，固定UFP/GPIO模式。使用KiCad标准TUSB320符号，逐脚核对LAI数据表。VDD及OUT1/2上拉均接USB_3V3，独立于切换后的MCU电源。没有电池常供电连接。
- VBUS_DET串887k±1%，容差878.13–895.87k落在855–920k允许范围。CC1/CC2直接引至USB边界，整合时必须移除原板外部5.1k Rd，不能与芯片内部Rd并联。0.1µF靠近U4 VDD。
- OUT1/2各200k上拉为候选值，接收器漏电/RC待核算。200k不是数据表对OUT1/2给出的专用保证值。OUT3/ID不用，明确NC。未更改USB D+/D−。

## 授权逻辑的输入约束

有效稳定供电时，OUT1/OUT2为HH未连接、HL默认电流、LH为1.5A、LL为3A。上电、掉电及检测未完成必须判无效；不能把失电输出低当3A许可。默认状态不能区分SDP/CDP/DCP，不能单独批准500mA。

因此本次没有把原始OUT1直接连充电器EN。下一步加入电源有效/复位约束、许可组合、默认USB/BC1.2策略及限流状态。充电核心3.48k ILIM最大493.44mA之外的所有支路还需单独计入总预算。

## 模拟边界与二审

TUSB UFP 70µA为VDD=4.5V下典型值，无最大值；TPS709空载地电流最大值不能直接套用带负载状态。约0.11mA旁路只能作典型估算，不能声称已证明500mA总输入界限。

TPS709启动600µs上限有特定EN、负载及电容测试条件，不能直接保证慢升VBUS场景；TUSB要求VDD上升≤25ms。稳压器反向保护不等于所有掉电阶段零反灌，低输出电压时仍需核对行为。未来接收器不得经上拉/钳位给USB岛反向供电。VBUS浪涌、ESD、输入总电容与启动电流仍待完整前端审查。
