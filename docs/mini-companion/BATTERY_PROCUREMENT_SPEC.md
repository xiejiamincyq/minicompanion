# 电池包采购约束（选型阶段，不是下单清单）

本文件落实用户批准的单节锂电、优质来源和电芯本体NTC要求。尚无电池供应商/完整订货号被批准；503450只表示名义尺寸，不能替代规格书。

## 必须由供应商明确的项目

- 单节4.2V充满LiPo/Li-ion，正规制造商与可追溯批次；提供电芯和成品电池包准确型号及修订版规格。
- 名义容量、最小容量、循环寿命测试条件、允许充放电温度、储存条件、推荐/最大充电电流、持续及脉冲放电电流和脉冲时长。
- 优先电池包内置保护板，声明过充、过放、充/放电过流及短路阈值/容差/延迟/恢复。充电器不替代电池保护。
- 电芯本体贴合或嵌装NTC，优先供应商出厂三线线束。必须给R25、公差、完整R-T曲线或适用B区间及公差、NTC热耦合方式。
- 第三针NTC另一端必须明确接成品包PACK−或原始CELL−；两者不可混称。优先PACK−参考，使外部主板温监与系统地同域；保护断开时也要验证NTC不会旁路保护或误报可充。
- 三针防呆锁扣连接器的厂牌、型号、端子、线径、线序、观看方向、线长、出线位置；外壳颜色不能作为极性证据。
- 电池包最大实际长宽厚必须含保护板、胶带、NTC、折边、极耳与线出口，给制造公差、膨胀/寿命留量。现有34×50×5mm仅是旧外壳模型，不能承诺所有503450装得下。
- 提供与具体成品型号关联的UN38.3测试摘要及适用IEC62133-2等测试资料。证书不能替代本项目整机验证，也不能混用其他电芯型号的证书。

## 电气预算门槛

电源模块按约3.3V/1A的预留输出能力研究，此值是设计容量而非已经测得的整机持续耗电。假设低压端2.8V、效率85%，1A输出对应电池约`3.3/(2.8×0.85)=1.39A`，还未计入其他直供负载。故不能仅凭“1000mAh”断定电流能力足够。

候选电池先要求至少1.5A持续输出规格，或由完整工作占空比/脉冲测量证明较低持续规格也满足。最终需含保护MOS/线束压降和电芯内阻再审；主板欠压关断应先于电池包保护动作，不能靠保护板反复跳闸维持运行。

充电电流以最终电芯推荐值为上限，另考虑温度和封闭壳体热限制。没有电芯规格，不允许将初稿300mA或旧TP4056电流直接作为冻结值。

## 装配和验收

优先采购已带NTC与保护的完整电池包，避免用户自行焊接软包极耳或拆开保护板。机械固定不能压迫电芯或刺穿封装；线束需应力释放和防错插。

先用限流电源/电芯模拟器验证主板充电与保护，再接合格电池。温窗使用精密电阻模拟和受控温度工装核对，包含NTC开路、短路、拔插和主控断电。不得要求初学者通过直接短路、过充真实锂电池来验证。

本阶段不采购。最终采购表必须替换本文件中的规格条件为实际供应商、订货号、数量、价格及尺寸证据；若无法满足现有包络或成本明显增加，再按用户授权边界决策。
