DESIGN 18: BOOK
===============
Hardcover book standing upright on a shelf. Screen on "front cover"
in portrait orientation. Faux page edges on fore-edge, hinged back
cover for PCB access. Spine has embossed title and bookmark-tab buttons.
Think "enchanted grimoire" or "smart desk reference book."

Overall: 130 x 90 x 30mm (H x W x D when standing upright)
Screen: 5.0" SSD1963 touch, 120x75mm module, 108x64.8mm active area
Target user: bookshelf integration, literary aesthetic

COMPONENT LAYOUT (exploded, front to back)
──────────────────────────────────────────

    Layer 1 — FRONT COVER (shell piece)
    ├── Screen window cutout: 109 x 66mm (portrait)
    ├── Screen module pocket: 121 x 76mm, 5mm deep from inner face
    ├── 4x screen retention clips
    ├── Embossed title recess on lower front face
    ├── Spine-side: 3x button plunger channels (6mm dia)
    ├── Bottom edge: USB-C slot (8.94 x 3.26mm)
    └── Wall: 2mm

    Layer 2 — SCREEN MODULE (120 x 75 x 4.5mm)
    ├── Portrait orientation (120mm vertical, 75mm horizontal)
    ├── Seated in front cover pocket
    ├── FPC cable exits toward bottom/spine
    └── Touch digitizer faces front through window

    Layer 3 — 3mm AIR GAP
    ├── FPC routing to PCB
    └── Foam spacers at corners for vibration isolation

    Layer 4 — PCB (110 x 65 x 1.6mm)
    ├── ESP32-S3-MINI-1 (15.4 x 20.5 x 2.4mm) faces back
    ├── 3x tactile switches on spine edge (extend through holes)
    ├── USB-C connector on bottom edge
    ├── SSD1963 display connector (40-pin FPC)
    ├── Mounted on 4x M2 standoffs from front cover inner bosses
    └── No speaker (or optional piezo buzzer)

    Layer 5 — BACK COVER (hinged door)
    ├── Hinged along spine edge (2x pin hinges, 3mm diameter)
    ├── Magnetic catch or friction latch on fore-edge
    ├── Inner face may have foam pad to hold PCB snug when closed
    └── Wall: 2mm

MOUNTING / ASSEMBLY NOTES
─────────────────────────

    1. Front cover + screen + PCB assembled as main unit
    2. Screen slides into pocket from inside, retained by clips
    3. PCB screws to front cover standoffs (4x M2x5mm)
    4. FPC cable connects screen to PCB
    5. Back cover attaches via pin hinges on spine edge
    6. Magnetic catch holds back cover shut during normal use
    7. To access PCB: open back cover like opening a book
    8. USB-C on bottom — cable drops down behind book on shelf
    9. Book leans against wall or other books for support
    10. Optional: small kickstand foot folds out from back cover


SPECIAL FEATURES
────────────────

    1. BOOKSHELF CAMOUFLAGE
       - Sized to blend in with real paperback books
       - 130mm tall ≈ standard mass-market paperback height
       - Page edges complete the illusion from the side
       - Spine title makes it look like a real book spine

    2. HINGED BACK COVER ACCESS
       - Opens exactly like a real book
       - Full access to PCB, wiring, USB-C connection
       - No screws needed to open (magnetic/friction catch)
       - Hinge durable for repeated open/close

    3. PORTRAIT SCREEN ORIENTATION
       - 5.0" screen rotated to portrait (108mm tall, 64.8mm wide)
       - Matches book page proportions naturally
       - Agent status displayed like a book page
       - Scrolling text feels like reading

    4. BOOKMARK-TAB BUTTONS
       - Buttons feel like pressing bookmark ribbons
       - Tactile and intuitive placement on spine
       - Color-coded tabs visible from the side
       - Natural thumb position when picking up the book

    5. OPTIONAL ENHANCEMENTS
       - Leather-texture filament for covers
       - Gold foil sticker for spine title
       - Felt bookmark ribbon (decorative, dangles from top)
       - Matching "bookend" stand accessory
