# ADR-001：采用 Power Path 与电芯 NTC

状态：用户已批准架构方向；具体实现由 Astra/Terra设计并审核。

日期：2026-09-20（承接2026-09-19审计）。

## 决策

采用单节LiPo/Li-ion、USB-C 5V、真正Power Path/Load Sharing。系统可边充边用，系统负载不能进入电池终止电流判断。关机仍可安全充电；独立POWER只控制系统供电，不破坏充电或保护路径。

温度必须测量电芯本体，优先电池包自带NTC及正式R-T规格，评估三针连接器；优先JEITA，允许等效硬件温度窗口。不得以PCB温感、充电IC结温或固定电阻代替电芯温监。

允许替换原TP4056、DW01A、FS8205A、ME6211。Astra负责具体型号决定和二审，Terra负责深度设计。不得仅因选择具体IC再次请求用户批准。

## 约束与后果

- MCU关机、固件缺失、复位、看门狗重置、USB热插拔均必须保持安全充电参数；依赖软件的方案必须证明所有硬件默认状态安全，否则不采用。
- 区分电池包保护与PCB保护的责任，核实保护断开后NTC参考地、ADC及USB反灌，避免并列保护相互旁路。
- 重新核算ESP32-S3、显示背光和NFC持续/峰值预算，检查3.3V稳压、热和USB默认电流；未选模块用明确设计预算并标待实测。
- 显著增加尺寸/成本、改变单节体系、USB目标或产品形态需用户确认；最终采购与PCB下单仍需明确授权。
- 保留原PCB中可复用接口；不能因通过ERC/DRC就宣称实物电池安全或RF可靠。

## 被替代路线

仅关机充电TP4056路线不再作为V1正式方向。旧POWER_AUDIT保留为决策历史，后续以本ADR和经Astra审核的POWER_DESIGN为准。
