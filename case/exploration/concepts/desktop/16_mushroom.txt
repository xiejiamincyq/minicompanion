PCB ACCOMMODATION NOTE
══════════════════════

    The standard PCB (110x65mm) is larger than the 50mm base.
    Two solutions:

    Option A: PCB in cap (preferred)
    ┌──────────────────────────────┐
    │  Cap interior is 70mm wide   │
    │  PCB mounts behind screen    │
    │  in cap cavity               │
    │  Screen FPC: short run       │
    │  Button/USB wires: through   │
    │  stem to base connector      │
    │                              │
    │     Cap cavity layout:       │
    │     ╔═══════════════════╗    │
    │     ║ PCB (fits in 70mm ║    │
    │     ║ cap diameter)     ║    │
    │     ║ ┌──────┐ ┌─────┐ ║    │
    │     ║ │ESP32 │ │Spkr │ ║    │
    │     ║ └──────┘ └─────┘ ║    │
    │     ╚═══════════════════╝    │
    └──────────────────────────────┘

    Option B: Enlarged base
    ┌──────────────────────────────┐
    │  Base enlarged to 120x70mm   │
    │  (oval/rounded rectangle)    │
    │  to accommodate full PCB     │
    │  Mushroom proportions shift  │
    │  to wider base (still works) │
    └──────────────────────────────┘

    Recommendation: Option A — PCB in cap.
    Base houses only USB-C breakout, weight, and connector.
    Wires route through hollow stem.

ASSEMBLY NOTES
══════════════

    1. Mount PCB to cap interior standoffs (4x M2)

    2. Mount screen module to angled bracket inside cap (4x M2)

    3. Connect screen FPC to PCB (short run inside cap)

    4. Mount speaker to cap dome interior (adhesive or bracket)
       Speaker fires down through gill slots

    5. Route button wires and USB extension cable
       through cap bottom hole into stem

    6. Slide stem onto cap pegs, twist-lock into place

    7. Connect button wires to tactile switches
       mounted in stem front face cutouts

    8. Route USB extension cable through stem to base

    9. Press stem bottom into base mortise

    10. Connect USB extension cable to USB-C breakout
        in base (or direct USB-C port in base bottom)

SPECIAL FEATURES
════════════════

    1. GILL SPEAKER GRILLE
       - Speaker hidden in hollow cap dome
       - Sound exits through radial gill slots on cap underside
       - Gill pattern is both decorative (mushroom-accurate)
         and functional (speaker ventilation)
       - Omnidirectional sound dispersion

    2. POLKA-DOT CAP DECORATION
       - Classic Amanita muscaria (fly agaric) toadstool look
       - White spots on red cap (or customizable colors)
       - Spots can be: painted, applied decals, or separate
         inset pieces (white dots pressed into red dome)
       - Cheerful, instantly recognizable silhouette

    3. TWO-PIECE DISASSEMBLY
       - Cap lifts off stem (twist-lock bayonet mount)
       - Access to PCB, screen, speaker for maintenance
       - Satisfying twist-click assembly action
       - Could swap cap colors/styles (future accessories)

    4. ANGLED SCREEN VIEWING
       - Screen on cap underside at ~30 degrees from vertical
       - Natural upward-facing angle for desk sitting position
       - Partially sheltered by cap overhang (glare reduction)
       - Unique viewing geometry — look slightly under the cap

    5. VERTICAL BUTTON COLUMN
       - 3 buttons stacked vertically on stem front face
       - Natural thumb reach when holding stem
       - Buttons follow the organic stem taper
       - Sized 6mm with 8mm spacing between centers

    6. ORGANIC FORM
       - No straight lines — everything is curved/tapered
       - Stem tapers: 25mm top to 35mm base (natural mushroom)
       - Cap dome is smooth hemisphere with slight overhang
       - Weighted flat base prevents tipping
       - Desk toy you want to pick up and fidget with

    7. USB-C THROUGH BASE
       - Cable enters from base bottom
       - Routes up through stem to cap PCB
       - Cable exits downward — clean desk appearance
       - Base sits flat, cable hidden underneath
