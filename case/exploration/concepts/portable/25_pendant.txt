DESIGN 25: PENDANT
==================
Oversized necklace pendant. Regular octagonal shape with screen
centered and tight ~2mm bezels. Jewelry-inspired finishing with
beveled/chamfered edges at 45deg that catch light beautifully.
Decorative bail/loop at top vertex for chain or cord passage.
Can also clip to shirt pocket with optional clip accessory.
Thin profile with slim battery.

Overall: 45mm x 45mm x 12mm (regular octagon, 45mm vertex-to-vertex)
Octagon flat edge: ~18.6mm (45mm / (1 + sqrt(2)) * sqrt(2) = 18.6mm)
Bail opening: 8mm ID
Weight target: ~35g with battery
Orientation: Portrait (screen fills octagon center)
Shell: 2-piece (front + back), press-fit + 2x micro screws
Finish: Polished, anodized, or plated (jewelry quality)

    Z-stack (compressed for 12mm target):
    1.5 + 2.5 + 1.5 + 1.6 + 0.4 + 3.5 + 1.0 = 12.0mm
    Note: Requires slim 3.5mm battery (~250mAh) and
    reduced back wall (1.0mm) and tighter gaps vs standard
    15.1mm stack. Achievable with careful FPC routing.


COMPONENT LAYOUT (exploded, front to back)
──────────────────────────────────────────

    Layer 1 — FRONT SHELL (octagonal, 1.5mm wall)
    ├── Screen window cutout (42 x 32mm, centered)
    ├── LED hole (2mm dia, above screen near top edge)
    ├── 2x button recesses in left/right flat edges (12.5 x 6.5mm)
    ├── 1x button recess in bottom flat edge (12.5 x 6.5mm)
    ├── Bail/loop integrated at top vertex (8mm ID opening)
    ├── 45deg chamfer on all 8 outer edges (2mm width)
    ├── Screen retention clips (4x, minimal)
    └── 2x micro screw sockets (hidden in edge chamfer)

    Layer 2 — DISPLAY MODULE (51.8 x 36.2 x 2.5mm)
    ├── Mounted portrait, centered in octagon
    ├── Module edges trimmed/filed to fit within 45mm octagon
    │   (51.8mm diagonal fits within 45mm octagon — tight)
    ├── FPC cable exits bottom, folds behind
    └── Held by minimal retention clips

    Layer 3 — 1.5mm AIR GAP (compressed)
    ├── Tight FPC routing (folded flat)
    ├── Side button plunger passages
    └── Minimal clearance

    Layer 4 — PCB (45 x 40 x 1.6mm)
    ├── PCB corners trimmed to fit octagonal shell
    ├── ESP32-S3-MINI-1 faces back (15.4 x 20.5mm)
    ├── 2x tactile switches on left/right edges (side-firing)
    ├── 1x tactile switch on bottom edge (side-firing)
    ├── 1x wake switch on bottom (near USB-C)
    ├── USB-C connector on bottom edge
    ├── Display FPC connector on top edge
    └── Vibration motor pads (bottom area)

    Layer 5 — 0.4mm GAP (tight)
    └── ESP32 module clearance (may need selective
        milling in back shell for 2.4mm module height)

    Layer 6 — BATTERY (28 x 28 x 3.5mm slim LiPo)
    ├── ~250mAh capacity (slim form factor)
    ├── Custom octagonal-friendly dimensions
    ├── JST pigtail to PCB (short)
    └── Centered in shell

    Layer 7 — BACK SHELL (octagonal, 1.0mm wall)
    ├── Battery cradle (shallow pocket)
    ├── PCB mounting posts (4x, short)
    ├── 2x micro screw threaded inserts
    ├── USB-C cutout on bottom flat edge
    ├── Vibration motor recess
    ├── ESP32 clearance pocket (milled 1mm deeper locally)
    └── Smooth polished exterior

MOUNTING / ASSEMBLY NOTES
─────────────────────────
- Shell: 2-piece octagonal (front + back)
- Assembly: press-fit alignment + 2x M1.4 micro screws
  hidden within the chamfer edge (nearly invisible)
- Bail integrated into front shell top vertex, reinforced
  internally with extra wall thickness (3mm)
- Display module may need edge trimming to fit 45mm octagon
  (51.8mm module diagonal vs ~45mm available — tight fit,
  module PCB tabs may need filing)
- PCB corners need trimming to octagonal profile
- Custom slim battery (28x28x3.5mm) for 12mm total depth
- Back shell has selective pocket for ESP32 module height
- Buttons recessed into 3 different flat edges of octagon
  (left = reject, bottom = action, right = approve)
- USB-C on bottom flat edge, small cutout
- Jewelry-quality surface finish required:
  - Option A: Polished stainless steel (CNC machined)
  - Option B: Anodized aluminum (multiple color options)
  - Option C: Plated brass (gold or silver tone)
  - Option D: High-polish resin (3D printed + coated)
- Chamfer faces can be contrasting finish (matte body +
  polished chamfers, or vice versa)
- Chain/cord not included — standard jewelry findings fit bail

SPECIAL FEATURES
────────────────
- Wearable as jewelry — oversized pendant necklace
- Regular octagonal shape with faceted gem-like chamfers
- 45deg bevels catch light from all angles
- Decorative bail for chain/cord (8mm opening fits most chains)
- Optional pocket clip accessory for shirt pocket mounting
- Jewelry-quality finishing options (polished, anodized, plated)
- Tight 2mm bezels maximize screen-to-body ratio
- Ultra-thin 12mm profile (slimmer than most pendants)
- Conversation piece — "is that a necklace or a computer?"
- Gender-neutral design — works as tech jewelry for anyone
- Multiple chain/cord options for different aesthetics
- Screen visible at a glance when worn at chest level
