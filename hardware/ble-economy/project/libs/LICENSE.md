# KiCad 封装来源

此目录中沿用标准库名称的封装来自 KiCad Footprint Libraries，作者为 KiCad Library Team 及各文件注明的贡献者。随工程附上所用封装以便打开和核查。标准库文件及基于标准库修改的版本按 CC BY-SA 4.0（含 KiCad 库例外）提供。[原库](https://gitlab.com/kicad/libraries/kicad-footprints) · [官方许可及设计使用例外](https://www.kicad.org/libraries/license/) · [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

A2_Candidate.pretty 下的 KT-0603R 基于 LED_SMD:LED_0603_1608Metric，按 KENTO 原厂图将焊盘改为 1=A、2=K。专用圆口与电感封装按各自厂图绘制。[圆口原厂图](https://atta.szlcsc.com/upload/public/pdf/source/20250916/86100E1A87EA13F8E80EA7E01FEEA2B4.pdf) · [电感原厂图](https://atta.szlcsc.com/upload/public/pdf/source/20240918/5AD8A1A0D9C2859F32750FF2CC514AFA.pdf)
