# A2 PCB 制造附件

本目录对应 `verification/a2_pcb_receipt.json` 绑定的保存态 PCB。它是两台原型的报价/审图候选，尚未完成供应商贴装预览和实板电气、温升及整机验收，不代表已下单或投产放行。

- 板：68 × 35 mm，2 层，1.6 mm，外层 1 oz，绿油白字，无铅 OSP。
- 装配：38 个板载元件均在顶面，115 个实际铜贴片焊盘。底面无器件。
- 孔：40 × Ø0.30 mm、2 × Ø0.40 mm 镀通孔；8 个非镀通孔。最小过孔环宽 0.15 mm，过孔双面盖油，无孔口侵入贴片焊盘。
- `a2-gerber-drill.zip`：8 个 Gerber 层、Gerber job、分离 PTH/NPTH Excellon。
- Gerber job 的表面处理明确为 OSP；尺寸采用 Edge.Cuts 中心线的 68 × 35 mm，而非官方绘图包围框包含 0.05 mm 描边的 68.05 × 35.05 mm。实际 Gerber 图形不作更改。
- `top-position-jlc.csv`：38 行嘉立创格式坐标；毫米，板左下角为原点，Y 向上。`top-position-kicad.csv` 保留官方原生导出。
- **J1 已作吸取中心修正**：封装锚点在插口前沿。JLC 坐标用 13.4 mm 主体中点 `(6.7, 22.5)`，而非原生锚点 `(0, 22.5)`，转角仍 90°。此更改仅影响坐标文件，不改铜与外壳锚点。贴装预览仍需核对 J1、D2、D3、U1、U2、Q1–Q3 的极性/转向与供应商封装原点。
- J1 封装局部 `+Y` 指向机身内部，KiCad `+90°` 将其转到板的 `+X`，因此插口朝板左；不是为对齐未知的供应商吸嘴零度而盲加旋转。嘉立创预览若采用另一封装零度，应按插口朝左、中心正极端子落在已核焊盘的实际图形对齐。
- BOM、线束及板外核心由 sourcing/整机资料提供；本 ZIP 不含板外焊接作业。

复核：用 KiCad 10 自带 Python 运行 `tools/verify_pcb.py`；仅在通过且板 SHA 一致后运行 `tools/export_manufacturing.py`。两者不保存 CAD，也不联网。修改 PCB/原理图后必须重新核验，旧报告与制造导出不能继续当作新版本证据。

`manifest.json` 记录 CAD 与附件 SHA256。PCB 原生 DRC 全部规则均启用（`ignored_checks=[]`），全严重度、全部走线错误、原理图一致性与重新铺铜检查均为 0，排除列表为空；这不代替贴装 DFM、充电/低压/互锁台架测试或外壳实装。
