# HW-NFC-018：电平角落审查与默认下拉修正

2026-09-30。结论：R5 从 100k 改成 47k 1%，增强默认断开余量；TMUX1511 继续作为评审候选，不能作为生产接口放行。没有增加器件或修改板框、主板、软件。

TASK ID：HW-NFC-018；MODEL：Astra 实施及自审；OBJECTIVE：核对总线电平及默认断开；INPUTS：017 网表、原厂数据；MUST KEEP：单节电池、Power Path、NTC、既有升压连接；ALLOWED TO MODIFY：NFC 候选与验证记录；DO NOT MODIFY：主板和用户软件；TOOLS：KiCad MCP、CLI、Python、官方手册；VALIDATION：网表不变、唯一阻值变化、ERC、KCL 角落计算、PDF；OUTPUT：018 候选和脚本；RISK：全温与动态行为、GPIO 负载规格、独立二审未闭环。

## 已核实的规格来源

- [ESP32-S3 v2.2](https://documentation.espressif.com/esp32_s3_datasheet_en.pdf)，表 5-4：输入高电平区间 0.75VDD 至 VDD+0.3；VOH 0.8VDD 的条件是高阻负载、3.3V/25℃。不能把这个 VOH 当作任意负载全温保证。VDD+0.3 是这里采用的 DC 工作边界，不应误称该手册表 5-1 的 GPIO 绝对最大值。
- [TMUX1511 Rev.B](https://www.ti.com/lit/ds/symlink/tmux1511.pdf)，5.5 节：SEL 的 VIH=1.2V、VIL=0.45V；输入漏电有规定测试偏置；内部下拉 6MΩ 只有典型值。VDD=0 掉电保护不覆盖任意棕断过程。
- [ST25R3916 Rev.8](https://www.st.com/resource/en/datasheet/st25r3916.pdf)，表 129：使用 I²C 专用参数，不能误用普通 CMOS/SPI 输出表；输入高电平为 0.8VDD_IO 至 VDD_IO+0.4。SDA 高阻与输入漏电分别列出 ±10µA，本轮保守相加，不表示两者必为独立叠加源。表中 3.3V、8mA 的 VOL 上界为 0.1VDD_IO，不能外推为任意电压、温度保证。
- 原厂 U216 图中 LDO 是 **TPAP7343D-33FS4**，不是 Diodes AP7343。经分销商找到 [TECH PUBLIC 署名手册](https://datasheet.lcsc.com/datasheet/pdf/df3dbbab015a06868aa121f4f307d9be.pdf?productCode=C2987061)，保存为 TPAP7343D.pdf。目视核对第 3–4 页：25℃、1mA 下 DC 精度 ±2%，负载调整率上界 1%，相关输入范围的线性调整率上界 0.35%；不采用销售页 AI 摘要的 1.5%。手册未给出足够的全温输出误差包络。

## R5 为什么修改

采用两路 SEL 各 2µA、两个监测开漏各 0.25µA、GPIO 50nA 的漏电幅值，合计 4.55µA。各器件测试偏置不同，这是设计预算，不是所有偏置下共同达到的实测漏电。保守忽略只有典型值的内部下拉帮助。

请求高阻时，100k +1% 对应 0.45955V，超过 0.45V 低电平边界；47k +1% 对应 0.21599V。故用 47k 留出余量。若 GPIO 在实际负载下能满足 0.8VDD，计算高请求的 SEL 下界约 2.0246V，仍高于 1.2V；该 GPIO 条件仍需验证，不能据此宣布控制端全温验收。

名义高请求时，R8+R5 支路约 55.79µA，比旧阻值多约 26.88µA；这只在请求为高时出现，需记入通信活动电流。

## 总线不是固定 3.3V

开关导通时，两侧上拉分别接主控电源与模块电源。`verify.py` 对两节点列 KCL，包含 4.5Ω 开关、两侧电源、上拉容差和漏电。不能直接把模块 3.3V 与主控门限相减，也不能把所有上拉当作同一电源。

25℃情景中，模块输出采用 ±(2%+1%+0.35%) 加法包络，即 3.18945–3.41055V。这可能重复计入部分误差，但仍不含温漂、瞬态与器件故障。模块上拉 2.2k 的 1% 容差为假设，待厂商确认；主板 4.7k 为 1%。

| 检查 | 最小条件余量 |
|---|---:|
| 主控正常电源下，主控高电平下界 | 0.7526V |
| 主控正常电源下，主控高电平上界 | 0.08291V |
| 最低欠压动作点附近，主控高电平上界 | **0.009544V** |

因此正常静态计算暂未显示必然不兼容，但不足以证明全温、棕断和动态兼容；不能说“3.18V 与 3.3V 必定不能接”，也不能说“欠压监测已彻底解决”。低电平灌电流、上升时间、线缆电容仍需要最终 GPIO 与实物检查。

若模块内部 3.3V 跌至 0、5V 仍存在且开关保持导通，忽略内部钳位的模型给出模块信号约 1.00V，高于该侧 VDD_IO+0.4 的工作边界。实际电压将受钳位与反灌影响，1.00V 不是实测预测。这个反例说明监测 5V 输入无法证明内部电压域掉电安全。

## 技术决定与下一步

保留本图作可复查基线，暂不将直通总线结构接入生产主板。下一步比较能分别约束两侧电平、并处理模块断电的接口方案；若依赖模块内部 3.3V 或 IRQ，必须明确原样四针模块能否提供，不能画出实际上不存在的连接。替代方案需同时核算成本、器件数和待机电流，避免不断叠加监测器而不解决根因。
