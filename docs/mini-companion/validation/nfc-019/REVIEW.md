# HW-NFC-019：收敛到有源缓冲器与受控供电

2026-09-30。本轮完成选型比较和计算，**尚未修改原理图**，当前 CAD 仍为 018。决定下一轮用 TCA9517ADGKR 替换直通 TMUX1511，增加 TPS22919DCKR，仅在 NFC 工作时给缓冲器供电。这是进入 CAD 验证的技术方向，不是生产冻结或批准增加整机预算。

TASK ID：HW-NFC-019；MODEL：Astra 研究与自审；OBJECTIVE：避免两个上拉电源经直通开关相连，控制新增待机功耗；INPUTS：018、TI 原厂手册；MUST KEEP：原样四针 NFC 模块、单节电池、POWER 边界；ALLOWED TO MODIFY：选型与验证计划；DO NOT MODIFY：主板、软件、既有候选连接；TOOLS：原厂资料、Python；VALIDATION：门限计算、功耗情景、资料哈希；OUTPUT：本记录、计算脚本；RISK：GPIO 实际灌电流、使能偏置、掉电漏电和动态行为仍需验证。

## 比较结果

| 方案 | 决定及理由 |
|---|---|
| 现有 TMUX1511 + 欠压检测 | 保留历史证据；不继续作为默认生产结构。两侧上拉通过模拟开关相连，018 已展示内部掉电反例 |
| PCA9306/TCA39306 类通道式转换 | 本轮不采用。仅换成传输晶体管不能独立证明模块掉电时没有主控上拉注入；需要额外偏置/使能审查 |
| ISO1640BDR | 保留功能参考，不优先。可分离高电平域，但静态电流为毫安级、封装较大；两侧共地时也不能宣传整机电气隔离 |
| TCA9517ADGKR + TPS22919DCKR | 优先进入下一轮 CAD。开漏有源缓冲、接口允许过压输入及掉电高阻；独立切断缓冲器供电，避免把毫安级功耗留在待机 |

## 下一版明确连接

TCA9517A 的 A 侧接模块，B 侧接 ESP32。两个 VCC 都接经 TPS22919 开关后的主控电源 `NFC_BUF_VDD`，不是接模块 5V。模块侧仍仅用原板内部 2.2k 上拉到模块自身 3.3V；主控侧保留 4.7k 上拉至 VLOGIC_SWITCHED。不在模块信号线上增设主控电源上拉。

这是两侧总线电源与缓冲器参考供电不同的用法：须用 5.5V 容限及门限逐项审查，不能直接照搬典型图的同电源上拉假设。不要把 VCCA 接 5V 再认为 3.3V 模块必能满足 0.7VCCA。

| 器件 | 引脚与连接 |
|---|---|
| U2 TCA9517ADGKR | 1 VCCA→NFC_BUF_VDD；2 SCLA→NFC_SCL；3 SDAA→NFC_SDA；4 GND；5 EN→NFC_BUS_CONNECT；6 SDAB→HOST_SDA；7 SCLB→HOST_SCL；8 VCCB→NFC_BUF_VDD |
| 新 U4 TPS22919DCKR | 1 IN→VLOGIC_SWITCHED；2 GND；3 ON→NFC_ENABLE；4 NC；5 QOD 与 6 VOUT 同接 NFC_BUF_VDD |
| 去耦 | 缓冲器两个 VCC 各就近 100nF；负载开关输入拟用 1µF，实际料号与有效容值待定 |
| R5 / R8 | 拟改为 22k / 2.2k，均 1%；保留 U3 的欠压禁用作用。旧 47k / 10k 不能直接沿用 |

U4 与升压共用 NFC_ENABLE；缓冲器的 EN 仍单独由请求与欠压钳位控制。缓冲器并不把高电平从 A 推挽驱动到 B，只能拉低或释放对应输出，因此主控侧高电平由主控侧电源定义。这解决了原结构的电源直通路径；芯片本身仍有漏电，不等于任何状态零反灌。

正常开机先使能电源，确认模块与缓冲器完成启动且总线空闲，再使能 EN；正常关机先在事务结束后关闭 EN，再撤销 NFC_ENABLE。不能把 U4 的典型启动时间当作最大等待保证。异常欠压强制禁用可能中断事务，恢复后需要总线恢复；这只是接口要求，不代写用户程序。

## 必须匹配的电平

TCA B 侧输出存在低电平偏移，上界 0.6V；主控按 018 的最小供电计算低电平接收边界为 0.7844V，条件余量 0.1844V。A 侧输出低上界 0.2V，模块条件余量 0.4379V。主控主动拉低 B 侧必须低于 **0.45V VILC**，GPIO 的高阻负载 VOL 不能替代真实灌电流保证，后续必须测量或取得合适规格。

EN 内部有上拉，低电平测试行的输入电流幅值最大 30µA，不能套用 TMUX 的下拉输入模型。拟用 22k 外部下拉和 2.2k 串联：条件高电平余量约 78mV；浮空低电平预算约 0.679V，低于 VCCB=2.7V 时的 0.81V 边界；欠压监测器灌电流约 1.48mA。漏电规格的偏置不同，计算不是全偏置保证。以上数值还未扣除实际供电开关压降，最终 CAD 复核需纳入。

## 功耗和成本约束

TCA 手册并非微安器件。采用 6mA 作为比较情景（来自不同测试行的 5mA、1mA 额度，不是 3.18V 实测或保证上界），按电池 3.7V、效率 85%：48 小时持续供电约耗 291.2mAh；若两天仅运行共 40 分钟，则约 4.04mAh。后者尚不包含上拉、负载开关、转换器和 NFC 本体。不能由此承诺整机续航。

TPS22919 手册在指定条件下给出全温关断电流上界 0.8µA，QOD 用于关断放电；其他引脚漏电、反向供电、真实关断残压仍须合并验证。若用户最终要求熄屏自动碰一碰，周期检测的占空比必须另算，不能用每天 20 分钟代替检测时间。
