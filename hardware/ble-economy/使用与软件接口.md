# 微雪核心 A2 的日常使用与软件接口

| 使用场景 | 操作 | 硬件行为 |
|---|---|---|
| 随身使用 | 正常运行短线插在核心的 USB-C 口，拔掉圆口充电线，将侧拨钮拨到 RUN | 保护电池经小板升至约 5 V，给屏和主控供电。OFF 挡直接禁止升压并隔断负载，控制过程不依赖固件。充电电路和保护电路仍接电芯。 |
| 普通充电 | 把配套 5 V 中心正适配器接入圆口 | 圆口内的切换触点动作并关闭升压；核心掉电后允许小板独立充电。温度由贴在电芯上的探头判断。拔掉圆口后，若遗留在 RUN 挡，设备会重新启动。 |
| USB 烧录或恢复 | 拨 OFF，拔掉圆口电源，拔下旁边的 RUN 短线，将普通 USB 数据线接入同一个核心 USB-C 口 | 由电脑给核心供电并烧录。卡在坏固件时，从侧面操作厂家 BOOT 与 RESET 进入 ROM 下载模式。完成后先拔电脑线，再插回 RUN 线。 |
| 电脑线和圆口同时插入 | 核心由电脑供电 | 正常完整线束把核心 5 V 送到禁充电路；电池停止充电。侧拨钮控制电池运行，插着电脑维护线时核心仍可工作。 |

选择外露可拔短线，是为了让电脑和电池升压永远只能占用同一个 USB-C 插座。代装方应使用机械固定的全长线束；核心 BAT 与 VBAT 均不接。充电必须用随设备配套的固定 5 V 电源。配套使用微雪国标 5 V 直出、中心正 5.5 × 2.1 mm 电源及其自带线。USB-C 运行短线接入小板 J4 的两根线，使用符合源端配置的 USB-C 公头。

| 按键 | 小板 J5 | 微雪 V2 P1 | 固件 |
|---|---|---|---|
| A | 2 | 1 / GPIO2 | 输入上拉，按下为低 |
| B | 3 | 2 / GPIO4 | 输入上拉，按下为低 |
| C | 4 | 9 / GPIO7 | 输入上拉，按下为低 |
| 公共地 | 1 | 13 / GND | 公共地 |
| 核心供电检测 | 5 | 14 / 5V | 专用电源状态信号，仅进入硬件禁充 |

两机离线互动和连手机使用同一套 ESP32-S3 BLE 硬件。后续固件可分别实现 BLE 中心、外设或相应的多连接角色。游戏、宠物状态及存档显示用板载 ST7789 系列 240 × 320 屏，横向界面为 320 × 240。断开 RUN 会立即掉电，固件应在操作期间分批保存进度。电池独立于核心，因此微雪例程读取原板 BAT 分压的结果不代表实际电芯电量。本版不增加扬声器或额外传感器。[微雪文档](https://docs.waveshare.net/ESP32-S3-LCD-2/) · [乐鑫 USB Serial/JTAG 下载说明](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-guides/usb-serial-jtag-console.html)
