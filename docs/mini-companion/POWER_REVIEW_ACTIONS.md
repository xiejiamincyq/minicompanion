# 电源方案二审：尚未允许落板

2026-09-21，Astra。用户已批准Power Path + 电芯NTC，具体器件选择仍由工程团队负责；以下属于设计待解决项，不向用户重复请求芯片型号批准。

`POWER_DESIGN.md` / `POWER_STATE_TABLE.md` 的HW-PWR-002R版本属于被二审退回的候选草案。BQ25185DLHR + TPS63802DLAR尚未冻结，原理图电源部分仍为上游电路。不要把“推荐候选”当作最终BOM。

1. **温度窗口**：按[BQ25185 Rev.B数据表](https://www.ti.com/lit/ds/symlink/bq25185.pdf)第8页，偏置电流36.5/38/39.5µA；热端进入阈值0.105/0.115/0.125V；冷端进入阈值0.9575/1.0075/1.0575V。以理想10kΩ、B3435模型计算，典型进入点为冷端1.74°C、热端59.51°C。只计IC极限值、尚不计NTC公差时，冷端约−0.20至3.72°C，热端约55.58至63.74°C。不能宣称符合0–45°C电芯；需完成窗口网络或换用合适充电器，并加入真实NTC曲线、公差、贴合误差、开短路和恢复条件。不能通过事后放宽采购规范掩盖不匹配。
2. **USB供电**：固定24kΩ的100mA档不因换成500mA电源而自动提高。草案“确认500mA供电即可无电池维护”的替代路径不成立。必须具体设计输入能力检测、限流档切换及重新采样时序，或者选用具备合适硬件输入管理的充电器；OFF、POR、MCU失效与USB挂起状态须分别核算。
3. **充电时间**：此数据表版本安全计时器为360min。100mA为1000mAh电池补满的理想CC时间已约10小时，尚不含CV和系统分流；必须核查计时器行为和所选容量，不能靠循环复位计时器解决不匹配。
4. **显示支路**：遵守`DISPLAY_POWER_CONSTRAINTS.md`；80mA是绝对最大，逻辑IDD未给出，3.3V名义电源存在正公差问题，低电池时SYS线性背光驱动也可能不足压差。
5. **POWER与故障**：落实独立机械开关及默认EN电平。开关仅控制系统负载，充电和电芯保护/NTC参考地连续；背光、ADC和USB等反灌路径须在原理图中解决。不能只关TPS63802而让常供电SYS上的背光仍工作。

计算公式：`Rtrip=Vtrip/ITS`，`T°C=1/(1/298.15+ln(Rtrip/10000)/3435)-273.15`。这些是初步模型计算，未替代电芯实际R–T表或硬件试验。
