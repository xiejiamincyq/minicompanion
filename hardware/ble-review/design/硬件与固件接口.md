# 使用场景与固件接口

两台设备采用同一套硬件。宠物状态、存档、小游戏、双机相遇和手机端交互使用现有 MCU、SPI 彩屏、三键、板载 Flash 与 BLE。宠物逻辑和配对协议留给软件项目。普通使用允许离线。整机每天约 20 分钟互动，其余待机，目标至少 48 小时。

| 已在 BLE-A0 根网表核对的接口 | 模组 GPIO | 电气或使用约定 |
|---|---|---|
| 三个游戏键 SW501 / SW502 / SW504 | GPIO17 / GPIO1 / GPIO5 | 分别为 BTN_ACTION / BTN_APPROVE / BTN_REJECT，按下接地。模型中面朝屏幕、USB 朝下，左/中/右的壳坐标 X 为 21/35/49 mm，分别对应 SW504/GPIO5、SW501/GPIO17、SW502/GPIO1；首板逐键实按确认后固化映射。 |
| 显示 SPI | SCLK GPIO12、MOSI GPIO11、CS GPIO41、DC GPIO40、RST GPIO39 | HS20HS072RX，ST7789 系列，320 × 240；逻辑电源随主轨关闭。 |
| 背光 | GPIO13 | 控制逻辑与 EN_RUN 联锁。待机时先降亮度并关闭背光；屏休眠需另发控制器命令。 |
| 电池电压采样 | GPIO2 | 保护包输出经 R1101/R1102 和隔离通道到 ADC。接通时 100k/100k 分压同时受到 22k 串联与 47k 下拉加载，理想直流比约 0.1975。首板以表计校准低电阈值。固件可灭屏、保存和休眠，彻底切断主轨依赖实体 POWER；低电时应提示用户关开关或充电。 |
| 恢复/调试 | GPIO0、EN、UART0 TX/RX | ROM 下载和串口可作为维修路径。USB 改版使用 GPIO19 D−、GPIO20 D+；具体服务操作以 USB 设计及布线验证为准。 |
| 双机、手机 | ESP32-S3 内置 BLE | 天线处保持净空。手机发现和双机连接可分别验证；两者并发、配对和数据格式由固件定义。 |
| 存储 | ESP32-S3-MINI-1-N4R2，4 MB Flash、2 MB PSRAM | 存档和游戏素材共享 Flash 分区，断电保留的状态写入非易失存储。彻底关机后的绝对时间可在下次连接手机时同步。 |

声音按本轮成本取舍省去。提示音可由 GPIO 的 PWM 控制频率与时长，软件难度低；例如村田 PKMCS0909E4000-R1 在 3 V、4 kHz 时的平均驱动电流计算值约 0.3 mA。成品仍需落实发声件、驱动峰值、壳体出音位置与响度，语音或音乐还需要不同的音频硬件。按预算优先，四个主要玩法均可用屏幕表达反馈。未来通过手机软件播放提示音也是可行的功能方向，取决于手机连接状态。[村田计算条件](https://www.murata.com/en-us/support/faqs/sound/sounder/char/sch0003)。

## 电源与样机验收

| 项目 | 设计依据及首板检验 |
|---|---|
| 供电 | 主轨设计值约 3.147 V，屏幕和模组共享的可用窗口为 3.0–3.3 V。在模组及 FPC 处量开关机、无线发射、全亮背光、低电池及 USB 插拔的极值。 |
| 充电 | 保护电池包标称 2000 mAh，设计充电电压 4.1 V。普通来源慢档约 77 mA，识别许可后的快档约 350 mA。2000 mAh / 77 mA 已约 26 h，超过安全计时；正常完整充电须用满足快档要求的电源及线缆。 |
| 保护包载流 | FLY.103450.2000 原厂整包 PCM 持续上限 1.5 A。按 3.0 V 电池、3.225 V 主轨 0.60 A、效率 80%、背光另取 0.11 A，估算包电流约 0.916 A，距连续额定约 0.58 A；需测启动与发射峰值。容量额定的充电上限为 4.2 V，本板用 4.1 V，软件常规低电应给电芯 3.0 V 放电终点留裕量。[原厂电池规格，第 5、13 页](https://atta.szlcsc.com/upload/public/pdf/source/20220914/13782EFE1AFAAC30421033D3D832A3F8.pdf) |
| 温度与装配 | 两只 4.7 kΩ NTC 串联并贴同一电芯表面。代装须固定且绝缘，确认线束极性、探头开短路禁充、温度响应。低电池和闭壳条件下测充电芯片、电芯温升。 |
| 续航 | 在电池端测运行平均电流、屏灭待机电流，计入稳压损耗、背光和 BLE 扫描。U603 的 PS/SYNC 由硬件接 PACK_POS，采用强制 PWM；整机待机实测需包含该损耗。若实测可用容量为 C（mAh），48 h 含运行 2/3 h、待机 47 又 1/3 h，需要满足 0.667 × 运行电流 + 47.333 × 待机电流 ≤ C。容量 C 取 4.1 V 充满至软件关机间的实测值。用两天操作周期复核。 |
| 双机与手机 | 两台装壳后分别在无线关闭、BLE 广播、扫描及连接状态试测；验证重连、附近有其他设备时识别正确，以及显示刷新和无线同时工作时的电源波动。 |

数字检查与首板测试分别记录。按限流裸板、电池模拟器、合格保护包、双机装壳的顺序，前一阶段异常时先检查原因。已保存的 BLE-A0 计算依据摘录于 [基线资料](../verification/baseline/)。
