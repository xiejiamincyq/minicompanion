================================================================================
  DEVOTCHI PORTABLE CASE - CONCEPT 10: CAPSULE / PILL
================================================================================

  Pill-shaped (stadium shape) with fully rounded ends. Landscape orientation.
  Semicircular ends with 24mm radius. Very smooth, no sharp edges anywhere.
  Comfortable palm grip with rounded ends fitting naturally in hand.

  Overall Dimensions: 90mm wide x 48mm tall x 16mm deep
  End Radius:         24mm (full semicircle at each end)
  Shell Split:        Along the long horizontal axis (front/back halves)

================================================================================
  SHELL SPLIT DETAIL
================================================================================

  The two-piece shell splits along the LONG horizontal axis:

  Side view (right end):

              .-------.   Front half
            / - - - - - \  ............  <-- split line (midplane)
            \ - - - - - /
              '-------'   Back half

  Split Features:
  - Split at 8mm from front (midplane of 16mm depth)
  - Front half: screen window, button holes, front wall + half of edges
  - Back half: battery pocket, screw bosses, back wall + half of edges
  - Perimeter snap clips (8 points around the oval perimeter)
  - 2x M2 screws on back for security
  - Split line hidden in the natural edge radius
  - Thin gasket in split groove for tight fit

  Assembly Sequence:
  1. Install display in front shell pocket
  2. Place foam spacer frame
  3. Install PCB onto standoffs (screw from back)
  4. Connect display FPC to PCB
  5. Install battery in back shell pocket, connect to PCB
  6. Snap front and back shells together
  7. Insert 2x security screws from back
  8. Install rubber screw plugs

================================================================================
  MOUNTING & ASSEMBLY DETAILS
================================================================================

  Display Mounting:
  - Recessed pocket in front shell: 52.0 x 36.4mm
  - Pocket depth: 2.5mm, centered in body
  - Adhesive foam frame for retention + vibration isolation
  - FPC folds right and connects to PCB below

  PCB Mounting:
  - 4x M2 standoffs in back shell (3.0mm tall)
  - PCB centered in body
  - 45mm wide PCB fits in 90mm body with 22.5mm margin each side
  - Margins used for: edge rounding structure, USB-C routing, wake button

  Battery Mounting:
  - Centered pocket in back shell
  - Foam-lined pocket walls
  - Double-sided tape for retention
  - JST connector with strain relief

  Button Mounting:
  - 3 buttons on flat bottom edge of front shell
  - Standard 12 x 6mm caps
  - Tactile switches on PCB bottom edge
  - Caps press-fit in shell, posts align with switches
  - Flat bottom edge provides stable button surface

  Shell Assembly:
  - 8 perimeter snap clips (evenly spaced around oval)
  - 2x M2 security screws on back
  - Snap clips engage with satisfying click
  - Silicone gasket in perimeter groove

================================================================================
  SPECIAL FEATURES
================================================================================

  1. Pill/Capsule Shape:
     - Stadium geometry (rectangle + 2 semicircles)
     - Fully continuous curves, no flat faces (except bottom edge)
     - Visually distinctive, unlike any typical gadget
     - Mathematically clean geometry (easy to CAD/manufacture)

  2. Ergonomic Palm Grip:
     - Rounded ends fit naturally between thumb and fingers
     - Hold landscape with thumbs on buttons
     - Left thumb rests on rounded end, right thumb on buttons
     - Can also palm the whole device comfortably

  3. No Sharp Edges:
     - 24mm end radii + 8mm depth edge radii
     - Smooth everywhere, safe in pockets
     - Feels like a large capsule or smooth pebble

  4. Landscape Orientation:
     - Natural widescreen format for status display
     - 90mm width provides comfortable two-hand grip
     - Screen centered for balanced visual weight

  5. End-Mounted Ports:
     - USB-C on left end: charging cable doesn't interfere with grip
     - Wake on right end: natural thumb position
     - Clean front and back surfaces

  6. Two-Piece Shell:
     - Splits along long axis (front/back)
     - Split line hidden in edge radius
     - Clean, minimal visible seam
     - Easy assembly with snap clips + screws

  7. Table Rest:
     - Flat zone on back prevents rocking
     - Can sit screen-up on desk
     - Slight back curvature keeps it from sliding

  8. Pharmaceutical Aesthetic:
     - White or pastel colored shell (pill-like)
     - Optional: two-tone color (front/back halves different colors,
       like a medicine capsule)
     - Smooth matte or semi-gloss finish
     - Embossed "DEVOTCHI" text along top curve
     - Fun color combinations:
       * White/coral
       * Mint/white
       * Lavender/cream
       * Sky blue/white
